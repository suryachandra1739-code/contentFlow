01. Access & Credentials

🔑 System Access Credentials

Use the following pre-configured administrator and agency credentials to log into the main workspace. In production, these should be updated or rotated from the admin panel.

User Role Account Email Initial Password Access Type
Agency Administrator admin@company.com password123 Full Administrative Control
Creative Team admin@contentflow.com password123 Campaign Creation & Setup Only
ℹ️
Security Recommendation: For production deployments, log into the dashboard using one of these accounts, navigate to settings, and change your password. Alternatively, you can use the "Forgot password?" option on the login screen.

How Client Accounts Get Access

To keep the platform highly secure, clients do not have default, hardcoded passwords. They are granted access via an invitation flow:

1

Invitation Generation

An agency administrator invites the client from the Clients tab in the dashboard by typing their name and email.

2

Security Verification Link

If a mailing system (Resend API) is configured, the client receives a secure email. If not, the dashboard exposes an invitation link that the agency administrator can copy and send manually (via Slack, WhatsApp, email, etc.).

3

Password Assignment

Upon clicking the invitation link, the client is redirected through a secure authorization callback (using PKCE verification) and lands on the password setting page to establish their own private password.

02. Infrastructure & Data Flow

⚙️ Infrastructure & Data Architecture

ContentFlow utilizes a high-performance modern web stack consisting of a Next.js App Router server, a Supabase PostgreSQL database, and Cloudflare R2 object storage. This ensures zero-bottleneck media processing and absolute tenant isolation.

Why We Use This Setup (No Server Load)

Traditional servers break down when creators attempt to upload large content. ContentFlow resolves this with a Presigned Media Pipeline:

Instead of routing heavy video bytes through our app server (which introduces lag and crashes), the browser client directly obtains a short-lived authorization token from the Next.js API. The browser then streams the media bytes directly from the user's hard drive straight to Cloudflare R2 Object Storage.

Row Level Security (RLS) & Client Privacy

Data privacy is critical when managing multiple client brands. Supabase enforces PostgreSQL Row Level Security (RLS) directly on the database level:
Each query executed automatically validates the client's session ID. Clients can only select rows belonging directly to their own campaigns, preventing cross-tenant leakage even in the event of an application code error.

03. Content Lifecycle

🔄 The Content Approval & Feedback Lifecycle

A post moves systematically through four status states. Each status change automatically generates an entry in the system audit log and locks/unlocks various capabilities on the client's screen.

Detailed State Definitions

Status Visibility & Access Description & Workflow Action
Draft Agency Crew Only Creators write post text and upload media. Visible only within the creator dashboard. Editing is unlocked.
Pending Client & Agency The post is published to the public review portal. Editing is locked. Client receives notification to approve or reject.
Approved Read-only (Locked) Client marks the post approved. The asset is locked from edits. Approved date, timestamp, and actor are logged in database.
Revision Client & Agency Client requests revisions. Comment input opens. The post status is set back to editable for agency crew.
⚠️
Self-Destructing Portal Link: By default, public review tokens are active for exactly 7 days from creation. After this period, the link self-destructs and will redirect clients to a 404 page to protect secure staging URLs.

04. Agency Operations

💼 Agency Workspace Guide

This manual covers setup, project management, content creation, and invitation workflows. Log in using `admin@company.com` or `admin@contentflow.com` to access these features.

👥
1. Create a Client Profile
Go to the Clients tab in the sidebar. Click Add Client. In the glassmorphic modal, fill in the company name and set a brand avatar color. Profiles are isolated.
📁
2. Create a Campaign Project
Select the Projects tab. Click New Project. Assign a name, choose the client from the drop-down selector, and hit create. This isolates posts by brand.

How to Send Review Links to Clients

Once you are ready to request client approval on post assets, use the following guide:

1

Configure Client User (First Time)

On the Clients dashboard page, locate the brand card and click the Invite Login link. Provide the client's email. This sets up their database record.

2

Copy the Invitation Link

If Resend is not configured, a pop-up appears displaying a copyable invitation link (e.g. https://contentflow.com/auth/confirm?token_hash=...). Copy this link and send it directly to your client.

3

Create Post and Obtain Review Token

Navigate to the project and click + New Post. Add text, scheduling, select the platform, and upload the image or video. Set status to Pending.

4

Copy Review Link

On the Post Details page, click the Copy Review Link button. It copies the public, secure link directly (e.g. https://contentflow.com/review/<unique-token>). Send this link to the client for one-click review.

💡
Direct Login Alternative: If clients complete the password setup, they can also simply log into the site directly at /login. The middleware automatically detects their role and routes them directly to a custom, private client dashboard.

05. Client Portal Guide

📱 The Client Portal (Client Side Guide)

This section is written directly for client stakeholders. You can print or copy this page to share with your clients to ensure they understand how to use the portal without any training.

1

Open the Secure Staging Link

Click the review link sent to you by the agency. This will open a premium, private web page that does not require login, displaying the specific post that needs your review.

2

Review the High-Fidelity Mockup

Observe the layout. The preview engine automatically models the content's appearance exactly as it will look when live on the selected platform (including text boundaries and aspect ratios for Instagram, Facebook, or YouTube Shorts).

3

Take Action: Approve or Request Changes

• Approve Post: If it looks perfect, click the green Approve Post button. This locks the post as ready for the agency's scheduling queue.
• Request Changes: If you need edits, click Request Changes. A text box will appear for you to detail what needs to be fixed.

4

Real-time Comment Chat

Use the comment panel on the right of the screen to chat directly with creators. The conversation is updated in real-time, allowing immediate feedback loop iteration.

Interactive Preview Support

The client portal renders realistic mockups of posts across three major social layouts:

📷 Instagram Layout
Renders the post inside a simulated phone screen with instagram-header styles, profile picture, actions bar, and description.
📘 Facebook Layout
Simulates desktop feed styles, client branding, and the typical desktop interaction panel.
🔒
Absolute Privacy: You will only ever see your own brand assets. All client accounts are fully sandboxed, ensuring that no other company has access to your scheduled campaigns.
